# Moderation GUI

**Moderation GUI** — серверный модерационный инструмент для Minecraft 26.3 на Fabric. Проект находится в активной разработке.

## Назначение

Мод объединяет управление игроками, рангами, правами доступа, наказаниями и журналом действий в единой системе. Сервер остаётся авторитетной стороной: клиентский интерфейс не должен самостоятельно определять права или выполнять административные операции.

## Разделы интерфейса

- **Players** — профили игроков, заметки, история и назначенные ранги.
- **Ranks** — создание и настройка групп, приоритеты и наследование.
- **Permissions** — групповые и индивидуальные разрешения.
- **Punishments** — наказания и управление их сроками.
- **History** — история действий и наказаний.
- **Settings** — настройки мода.
- **Activity Log** — журнал действий персонала.
- **Analytics** — расширенная статистика сервера (Pro).
- **Bulk Moderation** — массовые WARN/MUTE/BAN до 25 игроков с атомарным аудитом (Pro).

## Реализовано в текущей ветке

- SQLite с версионированием миграций и транзакционным обновлением схемы.
- Хранение профилей игроков, включая офлайн-профили; GUI показывает назначенные ранги и краткие заметки, поиск работает по имени и UUID.
- Репозиторий рангов и назначений с защитой от циклического наследования.
- Репозиторий наказаний BAN, MUTE и WARN, включая временные сроки и отзыв.
- Репозиторий журнала административных действий.
- Автоматическая регистрация входа и выхода игроков, сохранение времени последнего посещения.
- Применение активного BAN при входе игрока.
- Серверная блокировка публичного чата и командных сообщений для игроков с активным MUTE.
- Просмотр истории наказаний, включая снятые и истёкшие записи.
- Команды профилей, истории, KICK, WARN, MUTE, BAN, временных наказаний и снятия наказаний.
- Команды создания, удаления и назначения рангов с транзакционным аудитом.
- Команды управления персональными и групповыми разрешениями с журналированием.
- Серверные настройки `enforce_bans` и `enforce_mutes` с проверкой значений и атомарным сохранением.
- Pro: экспорт последних 200 записей Activity Log в CSV с проверкой редакции и прав доступа.
- Pro: расширенная аналитика профилей, рангов, активных BAN/MUTE, предупреждений и активности модераторов.
- Pro: массовая модерация до 25 игроков одной транзакцией; частичное применение при ошибке исключено.
- SQLite JDBC включается в сборку как вложенная зависимость.

## Сборка

Для сборки требуется JDK 25 и установленный Gradle 9.8.2 или совместимая версия. Пока Gradle Wrapper не добавлен, локальная сборка выполняется командой:

```bash
gradle build
```

## Статус

Проект не является релизной версией. Клиентская навигация, клавиша открытия (O), загрузка серверных данных и постраничный просмотр подключены. В GUI доступны формы заметок игроков, управления рангами, разрешениями, наказаниями и серверными настройками; действия отправляются серверу, где права проверяются повторно. History и Activity Log доступны для просмотра. Настройки `enforce_bans` и `enforce_mutes` сохраняются в конфигурации сервера.

Последняя завершённая проверка GitHub Actions для коммита `ff2d648` завершилась успешно в обеих редакциях: Free и Pro. В обоих заданиях выполнены `clean build` и тесты Gradle; JAR-файлы сохранены как артефакты CI. Проверка выполнялась на JDK 25. В GUI доступны постраничная навигация кнопками и колесом мыши, серверный поиск по разделам, точный поиск офлайн-профилей вкладки Analytics и Bulk Moderation в Pro. Расширенные фильтры и тестирование в реальном клиенте и на выделенном сервере Minecraft ещё не завершены. Повреждённый файл настроек восстанавливается к безопасным значениям по умолчанию. Поэтому проект пока не готов к релизному использованию.
