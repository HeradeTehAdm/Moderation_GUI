# Редакции Moderation GUI

Проект развивается в двух редакциях: **Free** и **Pro**.

## Принцип разделения

Free — самостоятельная версия для небольших и средних серверов. В ней остаются базовые инструменты модерации, профили игроков, наказания, ранги, разрешения и журнал действий.

Pro предназначена для расширенных административных процессов: аналитики, экспорта аудита, массовых операций и настройки оформления интерфейса.

Базовая защита сервера не должна становиться платной функцией. BAN, MUTE, KICK, WARN, проверка разрешений и базовый журнал остаются в Free.

## Сборка

По умолчанию Gradle собирает Free:

```bash
gradle clean build
```

Сборка Pro:

```bash
gradle clean build -Pedition=pro
```

Явная сборка Free:

```bash
gradle clean build -Pedition=free
```

JAR получает соответствующий суффикс версии и имени файла. Внутри JAR хранится метаданный файл редакции, который читает серверный `EditionManager`. Клиент не может переключить редакцию настройкой интерфейса.

## Текущий статус

Сейчас реализованы параметр сборки, метаданные JAR, матрица функций и серверная проверка возможностей. В Pro доступны экспорт последних записей Activity Log в CSV командой `/moderationgui export [limit]` (до 200 записей) и расширенная аналитика командой `/moderationgui analytics` и вкладкой Analytics. Аналитика показывает количество профилей, активность за 30 дней, ранги, назначения, наказания, активные BAN/MUTE, предупреждения, активность модераторов и наиболее часто наказанных игроков. Обе редакции собираются отдельно; CI публикует JAR как артефакты GitHub Actions.

**Важно:** Pro пока является preview-сборкой для разработки. Коммерческая лицензия, оплата, активация ключей и серверная проверка лицензии ещё не реализованы. Сам параметр `-Pedition=pro` не является защитой от копирования и не должен считаться готовой системой продажи. До публичного коммерческого запуска потребуется отдельная лицензирующая архитектура и юридическая проверка условий распространения.

## Матрица возможностей

| Возможность | Free | Pro |
|---|:---:|:---:|
| Профили игроков | Да | Да |
| BAN / MUTE / KICK / WARN | Да | Да |
| Ранги и разрешения | Да | Да |
| Базовый журнал действий | Да | Да |
| Расширенная аналитика | Нет | Да |
| Экспорт аудита | Нет | Да |
| Массовая модерация | Планируется | Планируется |
| Пользовательские темы GUI | Планируется | Планируется |

Матрица в коде описывает минимальную редакцию для каждой возможности. Реализация Pro-функций будет добавляться отдельно, с обязательной проверкой редакции на сервере.
